Entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

`main.py` writes a single funny sentence (at most 200 characters) to `/output/entry.txt`: a smartwatch congratulating its wearer for standing up — the saddest applause ever received. No network, no input, deterministic.

Run it:

```sh
python3 main.py
```
